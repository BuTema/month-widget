# Календарь — виджет для Google Календаря

Компактный полупрозрачный виджет с сеткой месяца (Kotlin + Jetpack Glance, Android 8+).

## Что умеет

- Месяц целиком (4–6 недель по числу строк в месяце) или фиксированное число недель: 1–5, начиная с текущей.
- В клетке дня видно 2–4 события (по настройке), «+N» — сколько ещё не поместилось.
- Фон: непрозрачность 0–100 %, тема системная / тёмная / светлая, размер текста 8–12.
- Только Google Календарь: читаются календари аккаунтов Google, уже синхронизированные на телефоне. Вход в аккаунт и интернет виджету не нужны.
- Скрытие событий:
  - включать/выключать отдельные календари;
  - переключатель на каждое название события (повторяющиеся серии скрываются целиком) — для звонков, на которые вас позвали, но вы не ходите;
  - скрывать отклонённые и/или приглашения без ответа.
- Тап по дню открывает календарь на этой дате, стрелки ‹ › листают месяц/недели, тап по названию месяца возвращает к текущему.

## Сборка APK

Локально Gradle-обёртки в проекте нет, поэтому проще всего GitHub Actions:

1. Создайте репозиторий и залейте в него содержимое этой папки (ветка `main`).
2. Вкладка **Actions → Build APK** (запускается сама после пуша или кнопкой **Run workflow**).
3. Скачайте артефакт `month-widget-debug` → `app-debug.apk`, установите на телефон.

Либо откройте папку в Android Studio (Ladybug или новее) и нажмите Run.

## Установка виджета

1. Откройте приложение «Календарь», нажмите **Разрешить** доступ к календарю.
2. Удерживайте пустое место на рабочем столе → Виджеты → «Календарь» (рекомендуется 4×4 и больше; для 5 недель и 2 событий в клетке — 4×4 или выше).
3. Всё настраивается в приложении (шестерёнка на виджете открывает его же).

## Заметки

- Настройки общие для всех экземпляров виджета.
- Виджет обновляется при смене даты, при изменении календаря (если прошивка присылает уведомление) и страховочно раз в 15 минут.
- На прошивках с агрессивной экономией батареи (в т.ч. OriginOS/Funtouch) добавьте приложение в исключения оптимизации батареи и разрешите автозапуск — иначе обновления могут задерживаться.
